会员管理系统

时间：2026.09　类型：个人项目　技术栈：Python · 列表 / 字典 · 文件读写 · 命令行

项目背景

学习完 Python 基础语法后，想用一个完整的小工具把「数据结构 + 文件持久化 + 命令行交互」串起来，而不是停留在单个知识点的练习题上。

主要功能

  • 会员信息录入：姓名、电话、等级、积分等字段
  • 查看全部会员、按姓名查询、修改与删除
  • 保存到本地文件，下次启动自动读取，数据不丢失
  • 各功能内部支持连续操作，输入 0 返回主菜单

我的工作

用列表保存会员、用字典保存字段；主菜单用 while 循环和 if/elif 调度；增删改查各自封装成独立函数，查询逻辑抽成公共函数复用；加入输入校验与异常处理，避免非法输入导致程序崩溃。

收获

理解了「主程序 / 功能模块 / 数据存储」的分层写法，也第一次真正体会到：把重复逻辑抽成函数，代码会短很多，改起来也更容易。

51 单片机智能密码门禁

时间：2026.03　类型：课程设计　技术栈：C · STC89C52 · LCD1602 · 4×4 矩阵键盘

项目背景

以 STC89C52 为主控做一套电子密码门禁，替代传统钥匙，练习键盘扫描、液晶显示与状态控制的完整硬件链路。

主要功能

  • 矩阵键盘输入密码，LCD1602 实时显示输入状态（用 * 掩码）
  • 密码正确则驱动开锁，播报提示音
  • 密码错误累计计数，连续错误后锁定一段时间并报警
  • 支持在管理员模式下修改密码

我的工作

负责硬件接线与程序编写：实现 4×4 矩阵键盘的行列扫描和按键消抖；按 LCD1602 的指令/数据时序编写显示驱动；用状态机管理「输入 → 校验 → 开锁 / 锁定」的流程。

收获

从原理图、面包板到实物调试全部走了一遍，学会了看时序图、排查引脚接触不良和上拉电阻这类「代码没错但硬件不工作」的问题。

智能循迹避障小车

时间：2025.04　类型：课程设计　技术栈：C · 51 / STM32 · L298N · 红外 / 超声波传感器

项目背景

做一台能自己沿黑线行驶、遇到障碍物能绕开的小车，把传感器采样、电机控制和决策逻辑整合到一个系统里。

主要功能

  • 循迹模式：红外传感器识别黑线，自动修正左右轮速度差保持沿线行驶
  • 避障模式：超声波测距，距离小于阈值时转向绕行
  • 通过 PWM 调节占空比控制车速，转弯更平顺

我的工作

完成传感器采样与阈值判断、L298N 电机驱动、PWM 调速以及循迹 / 避障两种模式的切换逻辑，并反复上车调试参数。

收获

认识到控制逻辑不能只靠「理想值」：传感器有噪声、地面反光会影响红外判断，必须留出容错和滤波，小车才能跑稳。
